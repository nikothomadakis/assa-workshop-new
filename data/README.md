# Workshop data

**[Download ASSA-Workshop-Day-Data.xlsx](https://raw.githubusercontent.com/nikothomadakis/assa-workshop-new/main/data/ASSA-Workshop-Day-Data.xlsx)**

This is the synthetic Protection, 2025Q2 workshop dataset from the final attendee pack.

Use it to populate the Google Sheet used by the supplied data-tool workflows. Preserve all six tab names and their column headers:

- `movement`
- `experience`
- `product_specs`
- `assumptions`
- `basis_change_detail`
- `policies`

If importing into a new spreadsheet, select that spreadsheet in the Google Sheets nodes of the data-tool workflows. Downloading this workbook does not change the Sheet connected to n8n.
